1. Overview

VirPull Companion (“the extension”) is a browser extension that works together with the VirPull desktop application. This policy explains what information the extension processes, how that information is used, and the choices available to you.

2. Information the extension processes

The extension accesses the currently active webpage only when you explicitly activate media detection. When you do, it may process:

  • The URL of the current webpage.
  • URLs and metadata associated with media detected on that page.

3. How the information is used

This information is used only to:

  • Detect supported media on the current webpage.
  • Send information about the media you select to the VirPull desktop application.

The extension does not use this information for profiling or for any purpose unrelated to these functions.

4. Where the information goes

Communication takes place directly between the browser extension and the VirPull desktop application on your computer. The extension does not intentionally send this browsing or media information to a VirPull-operated remote server.

5. Selling and sharing

The extension does not sell user information, and does not share user information for advertising or marketing purposes.

6. Your choices

The extension only accesses a webpage when you activate media detection, so you decide when it runs. You can uninstall the extension at any time through your browser's extension settings.

7. Children's privacy

VirPull Companion is not designed to collect personal information from children. As described above, the extension processes only webpage and media information, only when media detection is activated, and only to work with the VirPull desktop application on the user's computer. If you are a parent or guardian and have questions about your child's use of the extension, please contact us using the details below.

8. Changes to this policy

We may update this privacy policy from time to time. When we do, we will post the updated version on this page and revise the “Last updated” date at the top. We encourage you to review this page periodically.
